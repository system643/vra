# Creation Engine / Gamebryo (Bethesda)

**Signatures** : `*.esm` + archives `*.bsa` / `*.ba2`. Identité : `Skyrim.esm`, `Fallout4.esm`, `Starfield.esm`,
`FalloutNV.esm`, `Fallout3.esm`, `Oblivion.esm`, `Morrowind.esm` ; éditions VR : `SkyrimVR.exe`, `Fallout4VR.exe`.

**Règle d'or** : une **édition VR officielle passe toujours avant un mod**.

| Jeu | Plafond | Voie |
| --- | --- | --- |
| Skyrim / Fallout 4 (version plate) | 3 | Recommander Skyrim VR / Fallout 4 VR (achat séparé) + mods VR communautaires |
| Skyrim VR / Fallout 4 VR installés | 3 | Mods VR via gestionnaire à système de fichiers virtuel (Mod Organizer 2), extenders SKSE VR / F4SE VR |
| Autres (Starfield, Fallout 3/NV, Oblivion…) | 0–1 (+ inconnu) | Mods VR communautaires à rechercher ; geo-11 si DX11 |

**Méthode** : jamais de fichiers écrasés dans le dossier du jeu → gestionnaire de mods à système de fichiers virtuel ;
annulation = désactiver le profil de mods. Vérifier la compatibilité de chaque mod avec la version exacte du jeu.
