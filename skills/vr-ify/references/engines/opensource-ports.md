# Vieux jeux à moteur libéré (id Tech 1–4, Build, Wolf3D…)

**Signatures** : `id1/pak0.pak` (Quake), `baseq2/pak0.pak` (Quake II), `baseq3/pak0.pk3` (Quake III), `DOOM.WAD`/`DOOM2.WAD`
(Doom), `HERETIC.WAD`/`HEXEN.WAD`, `base/pak000.pk4` (Doom 3), `DUKE3D.GRP` (Build), `VSWAP.WL6` (Wolfenstein 3D).

**Plafond : 4** — la VR la plus profonde, grâce aux source ports VR (contrôleurs, interactions).

| Jeu | Voie |
| --- | --- |
| Quake | Quake VR (`install_tool_plan quakevr`) |
| Autres | Source port VR maintenu à rechercher (`vr-scout`) |

**Méthode** : le port VR s'installe **dans un dossier séparé** (VRA tools) et réutilise les données du jeu **acheté**
(copier ou pointer `id1/`, les WAD…). Jamais de données de jeu téléchargées ailleurs.
