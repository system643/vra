# Jeux émulés (consoles)

**Signatures** : exécutable de l'émulateur (Dolphin, PCSX2, DuckStation, RPCS3, PPSSPP, Cemu, xemu, Xenia, RetroArch…).

**Plafond : 0 à 1** (+ inconnus).

| Palier | Voie |
| --- | --- |
| 0 | Écran géant Virtual Desktop |
| 1 | geo-11 si l'émulateur rend en DX11 (choisir le backend DX11 dans l'émulateur) |
| ? | Fork VR de l'émulateur : à rechercher (`vr-scout`) |

**Garde-fou** : uniquement des images de jeux issues des consoles et cartouches de l'utilisateur ; aucun lien vers des ROM.
